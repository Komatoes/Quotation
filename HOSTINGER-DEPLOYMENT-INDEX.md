## 🔑 Critical Configuration

### Must Change in .env

```env
# Application
APP_ENV=production          # NOT local!
APP_DEBUG=false             # NOT true!
APP_URL=https://your-domain.com

# Database (from Hostinger Control Panel)
DB_HOST=localhost           # Usually localhost
DB_DATABASE=quotation       # Your database name
DB_USERNAME=your_username
DB_PASSWORD=your_password

# Linux paths (not Windows!)
DUMP_COMMAND_PATH=/usr/bin
```

### Will Auto-Generate

```env
APP_KEY=base64:xxxxx        # Generated by php artisan key:generate
```

## ❓ FAQ

**Q: How long does deployment take?**
A: 40-65 minutes depending on file upload speed and experience level.

**Q: Can I test before going live?**
A: Yes! Deploy to a staging subdomain first, then copy to main domain.

**Q: What if deployment fails?**
A: Check error logs: `tail -50 storage/logs/laravel.log` for details.

**Q: How do I update my code?**
A: `git pull origin main` then `composer install` then `php artisan cache:clear`

**Q: Do backups run automatically?**
A: Yes! After setting up cron job, backups run daily at 2 AM.

**Q: Can I backup to Google Drive too?**
A: Yes! See `GOOGLE-DRIVE-HOSTINGER-SETUP.md` for setup.
